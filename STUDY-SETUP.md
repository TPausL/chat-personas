## Recommended Study Workflow

### Daily Routine
1. **Morning Review** (30 min)
   - Review notes from previous lecture/exercise
   - Check upcoming deadlines

2. **Active Learning Session** (2-3 hours per course)
   - Attend lecture/exercise
   - Take structured notes
   - Complete assignments

3. **Evening Consolidation** (30 min)
   - Summarize key concepts learned
   - Update flashcards/Anki
   - Plan next day

## Per-Course Study Strategies

### 1. Computability and Complexity (buk) - TU
**Focus**: Problem-solving, proofs, algorithms
- ✅ Arcana indexed - ready for AI assistance
- Practice exercises regularly
- Focus on understanding proofs and reductions
- Use formal notation consistently

**Study Tips**:
- Work through exercise sheets before tutorials
- Form study groups for problem discussion
- Practice writing clear, rigorous proofs

### 2. Diskrete Strukturen (ds) - UE
**Focus**: Mathematical foundations, logic, combinatorics
- ⏳ Index Arcana for AI assistance
- Master proof techniques (induction, contradiction)
- Practice combinatorial counting
- Understand graph theory fundamentals

**Study Tips**:
- Create formula sheets for counting rules
- Draw diagrams for graph problems
- Practice translating problems to formal statements

### 3. Elements of ML and Data Science (elemlds) - VU
**Focus**: Algorithms, implementation, theory
- ⏳ Index Arcana for AI assistance
- Balance theory with practical implementation
- Understand mathematical foundations of algorithms
- Practice with real datasets

**Study Tips**:
- Implement algorithms from scratch
- Visualize concepts (decision boundaries, etc.)
- Connect theory to practical applications

### 4. IT-Security (itsec) - VU
**Focus**: Concepts, attacks, defenses, protocols
- ⏳ Index Arcana for AI assistance
- Understand threat models
- Learn cryptographic primitives
- Practice security analysis

**Study Tips**:
- Think like an attacker (threat modeling)
- Create attack/defense comparison tables
- Stay updated on current security news

### 5. Software Engineering (swt) - VU
**Focus**: Processes, design patterns, teamwork
- ⏳ Index Arcana for AI assistance
- Practice design patterns
- Understand development methodologies
- Work on team projects actively

**Study Tips**:
- Apply patterns to real code
- Practice UML and documentation
- Participate actively in team projects

## Quick Reference

### Study Session Checklist
- [ ] Set clear goal for session
- [ ] Remove distractions (phone, social media)
- [ ] Have all materials ready
- [ ] Take breaks (Pomodoro: 25min work, 5min break)
- [ ] Summarize what you learned
- [ ] Plan next session

### Before Lecture
- [ ] Review previous lecture notes
- [ ] Skim assigned readings
- [ ] Prepare questions

### After Lecture
- [ ] Review notes within 24 hours
- [ ] Fill in gaps
- [ ] Connect to previous knowledge
- [ ] Note unclear points to ask about

### Before Exercise/Tutorial
- [ ] Attempt all problems
- [ ] Note specific difficulties
- [ ] Prepare questions for tutor

## Contact and Collaboration

### Study Group Guidelines
- Meet 1-2 times per week per course
- Rotate who leads discussion
- Focus on problem-solving, not just answers
- Teach each other (best way to learn)

### Office Hours
- Prepare specific questions
- Bring attempted solutions
- Follow up on feedback
